## Description

_Linear algebra_ is the branch of ``mathematics`` that studies _vectors_. Which are arrows that represent objects and have magnitude and direction, as well as n-dimensional spaces.

---

## Key concepts

- **Scalar**: Simply as a number. A unique value that represents a magnitude.
- **Vector**: An ordered list of _scalars_/numbers.
- **N-dimension**: Indicates the number of elements inside a vector.
  Example: $\vec{v} = [2, 3]$ is $R^2$, $\vec{w} = [2, 3, 4]$ is $R^3$
