## Description

An _equation_ is a **mathematical statement that two** ``expressions`` **are equal**:

$$4 + 5 = 9$$
$$x -35 = 56k^2 + 3$$
$$x + 3 = 15$$

---

## Details

### First Grade

This _equations_ **must contain only 1 variable, raised to the first power**:
$$5x^{(1)}+9 = 3$$

Also, this statements must be true:
- a != 0
- ax + b = 0


### Solve for a Variable

To _solve a variable_ means to isolate that specific variable into one side of an _equation_, leaving the rest to the other side.


### Absolute Value

The absolute value of an `expression` is formally defined by:

$$
|a| =
\begin{cases}
a, & \text{if } a \ge 0 \\
-a, & \text{if } a < 0
\end{cases}
$$
#### Example
$$|9+x|=5$$
$$9+x=5 \ and \ -(9+x)=5$$
$$x=5-9 \ and \ -9-x=5$$
$$x=-4 \ and \ -x=5+9$$
$$x=-4 \ and \ -x=14$$
$$x=-4 \ and \ x=-14$$


$$| \frac{x^2+3x+2}{x^2-1} | = 4$$
$$| \frac{(x+1)(x+2)}{x^2-1} | = 4$$
$$| \frac{(x+1)(x+2)}{(x+1)(x-1)} | = 4$$
$$| \frac{x+2}{x-1} | = 4$$
$$\frac{x+2}{x-1}=4 \ and \ -\frac{x+2}{x-1}=4$$
$$x+2=4(x-1) \ and \ -(x+2)=4(x-1)$$
$$x+2=4x-4 \ and \ -x-2=4x-4$$
$$6=3x \ and \ 2=5x$$
$$x=\frac{6}{3} \ and \ x=\frac{2}{5}$$
$$x=2 \ and \ x=\frac{2}{5}$$
