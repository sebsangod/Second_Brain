## Details

### Linear Equation System

This means to solve more than one _linear equation_ at the same time.

![[linear_equation_system.png]]

In this kind of equation, the value we find when solving for a variable (commonly x, then y) must be true for all given equations.


### Types

The goal is to find the _point of intersection_ (where the two lines, or equations, intersect).

Thus, there is three types of _linear equation systems_:

![[linear_equation_system_types.png]]


### Methods to Solve Them

#### Substitution Method

The process in this method is to solve one variable for one of the given ``equation`` to then substitute the result in the other `equation`:

![[substitution_method.png]]


#### Equalization Method
In this method we solve all the ``equations`` for the same variable to equalize them, then we solve for the other variable and substitute that result into one ``equation`` to find both of the variables:

![[equalization_method.png]]


#### Reduction Method

The goal in this method is to transform the simplest ``equation`` in order to cancel one variable doing an ``equation addition`` with the other ``equation``:
