## Description

``Expression`` that **compares two or more quantities** using this symbols:
$$\lt \ less \ than$$
$$\gt \ greater \ than$$
$$\leq \ less \ or \ equal \ than$$
$$\geq \ greater \ or \ equal \ than$$

In an _inequation_ we **don't look to know the exact value of a variable, but its range of values**: greater than or less than other numbers.

___

## Details

### Compound inequalities

A _compound inequality_ is an _inequality_ that **combines two simple** _inequalities_:
$$x \gt 0 \ AND \ x \lt 4 \ :$$
$$0 \lt x \lt 4$$

### Operations

Same with a normal ``equation``, we can sum and subtract the same. The changes come when we try to:

#### Positive Numbers

With positive numbers the process is exactly the same as any _equation_:
$$\frac{x}{2} \leq 5$$
$$x \leq 5 * 2$$
$$x \leq 10$$


$$4x \geq 12$$
$$x \geq \frac{12}{4}$$
$$x \geq 3$$


#### Negative Numbers

With negative numbers, **every time we pass a multiplication as a division to the other side** (or viceversa), the _inequation_ **symbol changes its orientation**:
$$\frac{x}{-2} \leq -8$$
$$x \geq (-8)(-2)$$
$$x \geq 16$$


$$-3x \gt 6$$
$$x \lt  \frac{6}{-3}$$
$$x \lt -2$$


#### Compound Inequations

$$-10 \leq 2x-4 \lt 6$$
$$-10+4 \leq 2x-4+4 \lt 6+4$$
$$-6 \leq 2x \lt 10$$
$$\frac{-6}{2} \leq \frac{2x}{2} \lt \frac{10}{2}$$
$$-3 \leq x \lt 5$$
