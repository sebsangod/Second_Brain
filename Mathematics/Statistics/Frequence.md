## Description

Understanding _frequency_ tables and _relative frequency_ is crucial for any data analysis. These tools allow you to **see how many times a specific value appears within a dataset.** This can help you effectively identify patterns and trends in large volumes of data.

---

## Details

### Frequency

_Frequency_ simply indicates the number of times a particular value appears within a dataset.

Suppose we are analyzing the host cities of the World Cup throughout history. We would use a table listing each event by year, host country, and continent. To identify, for example, which continent has hosted the most World Cups, we would count the events listed in the “continent” column.

### Relative frequency

_Relative frequency_ takes it a step further. **How many times does a specific value occur compared to the total?** This is expressed as a **percentage**.

For example, if 23 World Cups have been held as of 2026, and we know that Europe has hosted approximately 48% of these events, this figure represents its relative frequency. In the case of Netflix, movies account for approximately 69% of the content, indicating a preference within the platform.
