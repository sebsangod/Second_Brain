## Description

Measures of central tendency are **values that represent a data set, showing a central point around which the data tends to cluster**.

---

## Details

### Mean

More commonly **known as the average**, is calculated by adding all the values in a data set and dividing the sum by the number of elements. It’s an excellent way to **identify the midpoint of the data**.


### Median

Is the **value in the middle of an ordered data set**. It is particularly useful for skewed data because it is not affected by extremely high or low values.


#### Odd set
Sort the values from lowest to highest. The _median_ **is the value in the middle position or**
$$
X_{\frac{N+1}{2}}
$$
Example: {1, 2, 2, 4, 5, 7, 9}. Median: 4 (position 4).


#### Even set
Sort the values and take the average of the two middle values by the following formula:
$$
\frac{1}{2} * (X_{\frac{N}{2}} + X_{\frac{N}{2}+1})
$$

Example: [1, 2, 3, 3, 4, 5, 7, 9]. Median: $\frac{3 + 4}{2} = 3.5$.


### Mode
Is the **value or values that occur most frequently in a data set**.

A data set can be unimodal (one mode), bimodal (two modes), or even have no mode if no value occurs more frequently than any other or if all values occur with equal frequency.
