## Description

_Matrix_ ``data structure`` (also know as _Grid_) is a **two-dimensional** ``array`` **arranged in rows and columns**.

It is commonly used to represent _mathematical matrices_ and is fundamental in various fields like mathematics, computer graphics, and data processing. _Matrices_ **allow for efficient storage and manipulation of data in a structured format**.
