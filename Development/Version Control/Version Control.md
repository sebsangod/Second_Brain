## Description

_Version control_, also known as _source code control_, is the practice of **tracking and managing changes to software code**. _Version control systems_ are software tools that help software teams **manage changes to source code over time**.

_Version control software_ **tracks all changes to the code** in a special type of ``database``. **If an error occurs, developers can go back in time and compare previous versions** of the code to help resolve the issue, while minimizing disruptions for all team members.
