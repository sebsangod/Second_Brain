## Description

In _relational databases_ (also known as _SQL databases_) the **information is organized as a set of tables with columns and rows.**

Relational database technology provides **the most efficient and flexible way to access structured information.**

The most popular _relational databases_ includes:

- ``MySQL``
- ``PostgreSQL``
- Oracle DB

### SQL

_Relational databases_ (also known as _SQL databases_) uses _SQL_: a programming language used to query, manipulate, and define data, and to provide access control.
